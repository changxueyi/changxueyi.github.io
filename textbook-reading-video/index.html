一本会翻开、会被逐句朗读的 3D 课本。

你给封面和文章页，可选目录页、对开页和要读的片段文案；其余交给流水线：识别、对齐、配音、建模渲染、字幕与质检。

01 / SET UP

建项目

复制素材，OCR 识别文字与坐标，生成高清书页贴图与翻页素材。

02 / ALIGN

对齐文案

把要读的片段切成句子，模糊匹配到页面文字，算出每句的高亮框。

03 / VOICE

配音混音

MiMo 男声播音腔逐句配音，叠钢琴配乐，混音到 −14 LUFS。

04 / RENDER

建模渲染

Blender 搭带厚度的立体书，相机逐句推近，红色 marker 跟随朗读。

05 / FINISH

字幕质检

合成松体字幕与标题，逐帧核对字幕、标题、响度后导出 mp4。

成片前的三道把关

每一条成片，都要先回答三个问题。

字幕是否逐字正确？高亮是否落在正在读的那一句？声音是否够干净、够响？

CAPTION / 字幕

字幕逐字对得上吗？

在每句中点抽帧，对字幕区域做 OCR，与朗读文本逐字比对，错字即报错。

HIGHLIGHT / 高亮

高亮落在该句吗？

校验每句的红色 marker 都在画面内、压在正文行上，且不挡住正在读的字。

AUDIO / 声音

响度达标吗？

整条按 −14 LUFS、真峰值 ≤ −1.5 dBTP 控制，句间留白，无爆音。

常见问题

需要准备什么，又有哪些边界。

我需要提供哪些素材？

必需：课本封面图、含要读段落的文章页图。可选：扉页、目录页、对开页，以及你想读的片段文案和小米 MiMo TTS key。不给文案时会从页面里挑一段，并告诉你挑了哪段。

只能做《背影》这类课文吗？

不限。任何一页印刷文字清晰的文章都可以，照片尽量拍正、拍清楚；一个视频对应一个摊开的跨页。

声音是真人录的吗？

不是，用小米 MiMo 语音合成的男声播音腔（默认音色「白桦」），可换音色或风格。

做一条要多久？

识别、对齐、配音、字幕等约几分钟；3D 渲染按时长，40 秒成片约 40–50 分钟（可先出半分辨率预览）。
