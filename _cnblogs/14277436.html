一、=>,->的意思：

->是对象bai执行方法或取得属性用的。
=>是数组里键和值对应用的。
二、用法

1、=> 的用法数组中用于数组的 key 和 value之间的关系例如：

$a = array('0' => '1','2' => '4',);echo $a['0'];echo $a['2'];

2、-> 的用法类中用于引用类实例的方法和属性例如：

class Test{function add(){return $this->var++;}var $var = 0;}$a = new Test; 

//实例化对象名称

echo $a->add();echo $a->var;
