1. PostMan使用

1. 使用postMan进行请求，记得添加Headers信息

 

 

 2. 记录一次遇到得小坑，在PostMman请求一个接口信息时候

ResponseVo<XXXXResVo> queryXXXXManage(XXXXReqVo XXXXReqVo);

XXXXReqVo对象为

public class XXXReqVo{
      private String pin；
      private String ip;
      Pirvate String src;
}

这个时候，需要使用PostMan请求，参数应该是

 

[{
    "pin": "creditTest001",
    "ip": "127.0.0.1",
    "src": "03"
}]

注意这里根据postMan ，请求的是一个对象，参数应该这样写（记得加入一个中括号）

 

 

如果请求的接口参数为一个对象，则应该在postMan中也要这样去写

这是请求的接口信息
Map<String,String> fun (Map<String,Object>  map);

需要在postMan中配置
[{
    "pin": "creditTest001",
    "ip": "127.0.0.1",
    "src": "03"
}]

记得加上一个中括号【】
